# 교환함 기능 테스트 체크리스트

백엔드 연결이 안정되면 같이 확인할 목록이에요.
기능마다 **정상 작동 / 입력값 오류 / 빈 데이터 / 서버 오류** 네 가지를 봐요.
기대 결과와 메시지는 `api-docs/*.yaml` 명세를 기준으로 적었어요.

- 표시: `[ ]` 미확인 · `[x]` 통과 · `[!]` 문제 있음 (비고에 내용 적기)
- 공통으로 볼 것
  - 요청 중에는 버튼이 비활성화되거나 로딩이 보이는지
  - 실패하면 사용자에게 이해할 수 있는 문구가 보이는지 (토스트 또는 화면 안 안내)
  - 데스크톱 브라우저 기준 (모바일은 이번 범위 아님)
- "서버 오류"는 백엔드를 끄거나, 주소를 잘못 넣거나, 500을 받는 경우로 확인해요.

## 명세와 화면이 다른 곳 (연결할 때 같이 정하기)

| 위치 | 내용 |
|---|---|
| 방 생성 모달 (`App.jsx`) | 방 이름 최대 20자 → 명세는 10자 / 필수 값 `roomMembersNumber` 입력칸 없음 |
| 내 방 화면 (`App.jsx`) | "○월 ○일에 만들어졌어요", 멤버 옆 색깔 점, "방 설정" 버튼 → 명세에 데이터·API 없음 (지금은 `ui-refresh.css`에서 숨김) |
| 사진 · 아바타 | 시안의 방 사진, 멤버·작성자 사진 → 명세에 이미지 필드 없음 (화면에서 뺌) |
| 내가 쓴 일기 | 목록 API 없음, 임시저장 여부(`isTemporary`)가 조회 응답에 없음 |
| TMI 작성 | `isFake`는 필수인데 시안에 선택 UI 없음 → 항상 `false`로 보냄 |
| TMI 결과 | 투표 직후 응답에만 결과가 있음 → 결과 화면으로 넘어갈 때 데이터를 넘겨줘야 함 |
